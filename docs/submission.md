# コード提出について

- 提出締め切り：**2月12日(金) 終日中**
- 提出先：
  - フォルダ命名規則
    - 例：個人名が「創価太郎」の場合
      - t.soka
  - SOBITS Member
    - NASサーバの以下の場所に，上記の命名規則に従って個人名のフォルダを作成しアップロードしてください
      ```
      /volume1/Competition/RoboCup/RCSO26_winter/code_submission/
      ```
  - Non-SOBITS Member
    - 以下の場所に上記の命名規則に従って個人名のフォルダを作成しアップロードしてください
    - [Google Drive]()
- 提出物：
  - メイン（パッケージ or コード）＋ 工夫したプログラム*
    - 工夫したプログラム：**SOBITSパッケージ以外(あれば)**で使用したもの
  - サーバ負荷低減のため，**Weightファイルなどの容量が大きいファイルは提出しない**でください
  - **zipファイル**にして提出してください
- 締切時間に提出されていなかった場合
  - ペナルティとして**1時間遅れるごとに-50点**

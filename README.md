# **RoboCup SOBITS Open Real Robot Leagueについて**

SOBITSでは，RoboCupを模した競技会である**RoboCup SOBITS Open**を年に2回，開催しています．これは，RoboCupに出場したことのないメンバー(主にB3，B4)のみなさんに，開発に必要な力を身につけてもらうことを目的とした競技会です．

まずはじめに，**Real Robot League**について述べます．SOBITS Openは先述の通り，夏と冬の年2回実施されます．Real Robot Leagueは，毎年2月に開催される，実機ロボットを用いた競技会です．学内外・学年を問わず，事前に参加申請を行えば，誰でも自由に参加できます．皆様の積極的なご応募をお待ちしております．

競技の開発は，1名で行ってもらいますが，競技で用いる要素技術は，SOBITSのパッケージとしてまとめられています．それらを使いこなすことで，初学者の方でも充分に1人で挑戦できる競技内容となっています．本競技会では，基本的に先輩から開発に関するアプローチは行いません．開発者の皆さんは，行き詰まった内容について積極的にアドバイスを求めるなど，**主体的な行動**を心掛けましょう．

本競技会での開発には，機能を実現する技術力はもちろん，壁にぶつかったときの突破力や，期限が決まった中で開発を進める計画力，その計画を実行する行動力など，様々な力が必要になります．

RoboCup SOBITS Openをとおして得た経験が，皆様の今後の研究生活に役立てられると，とても嬉しいです．
